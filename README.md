# Booking Bot

Telegram-бот для онлайн-запису клієнтів у барбершоп або салон. Клієнт обирає послугу, день і вільний час, а адміністратор отримує сповіщення і бачить розклад на день.

Демонстраційний проєкт: назва салону, послуги і графік задаються в `config.py` і легко змінюються під будь-який бізнес із записом (салон краси, майстерня, репетитор).

## Можливості

**Для клієнта**
- запис у чотири кроки: послуга → день → час → підтвердження
- показуються тільки вільні години, на один час не можна записатися двічі
- перегляд і скасування своїх записів
- список послуг із цінами, контакти

**Для адміністратора**
- сповіщення про кожен новий і скасований запис
- розклад на день: `/today`, `/tomorrow`, `/day 2026-11-20`

## Запуск

1. Створи бота в [@BotFather](https://t.me/BotFather) командою `/newbot` і скопіюй токен.
2. Встанови залежності:
   ```bash
   git clone https://github.com/SpellRey/booking-bot.git
   cd booking-bot
   python -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   ```
3. Скопіюй `.env.example` у `.env` і встав токен у `BOT_TOKEN`.
4. Запусти:
   ```bash
   .venv\Scripts\python bot.py
   ```
5. Напиши боту `/id`, встав отримане число в `ADMIN_ID` у файлі `.env` і перезапусти бота. Тепер сповіщення приходитимуть тобі.

Потрібен Python 3.10 або новіший.

## Структура

```
bot.py            запуск бота
config.py         токен із .env, послуги, графік роботи
schedule.py       розрахунок доступних днів і вільного часу
db.py             записи в SQLite
keyboards.py      меню і кнопки
handlers/
  booking.py      запис крок за кроком, мої записи, скасування
  admin.py        розклад для адміністратора
  common.py       /start, /help, ціни, контакти
tests/            тести розкладу і бази
```

## Тести

```bash
.venv\Scripts\python -m pytest
```
